# Sistema de Detecção de Fraudes

Sistema de detecção de fraudes em transações desenvolvido em **Python**.

O projeto está em fase inicial de desenvolvimento e tem como objetivo identificar transações potencialmente suspeitas por meio da análise de diferentes fatores de risco.

## Status

**Em desenvolvimento.**

Novas funcionalidades, regras de detecção e melhorias serão adicionadas conforme o projeto evoluir.

## Tecnologias

* Python
* Git
* GitHub

## Objetivo

Desenvolver progressivamente um sistema de análise de risco enquanto aplico e aprimorar conhecimentos de programação e desenvolvimento de software.
